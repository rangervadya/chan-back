# Camelion: запуск и перекраска по маске

## Что используется по умолчанию

В рекомендованной конфигурации `AI_BACKEND=sam2-local` генеративная модель Flux вообще не вызывается. Сервер делает следующее:

1. **SAM 2.1 Hiera Tiny** выделяет предмет по точке, на которую пользователь нажал в фотографии. Модель загружается с Hugging Face и кэшируется на сервере.
2. Локальный алгоритм перекрашивает пиксели внутри маски. Яркость, тени, блики, складки и фактура исходной фотографии сохраняются; за пределами маски пиксели не перекрашиваются.
3. При провале сегментации сервер возвращает ошибку, а не выдаёт изображение с неверно закрашенной областью за успешный результат.

Базовая перекраска **не использует платный API генерации и не расходует квоту Cloudflare**. Плата за сам сервер/хостинг остаётся. SAM 2 выполняется на CPU, поэтому первый запуск медленнее обычного; веса модели загружаются при первом запросе и сохраняются в `server/model_cache`.

SAM 2.1 Hiera Tiny: `https://huggingface.co/facebook/sam2.1-hiera-tiny`. Репозиторий и модель имеют лицензию Apache-2.0.

## Настройка

1. Скопируйте `.env.example` в `.env` в корне репозитория.
2. Установите сгенерированный серверный ключ `API_KEYS`:

   ```sh
   openssl rand -hex 32
   ```

   Не добавляйте этот ключ в публичный Git. Ключ приложения `API_KEY` должен совпадать с одним из значений `API_KEYS`. Учтите, что ключ, встроенный в мобильное приложение, можно извлечь: это ограничение злоупотреблений, а не полноценная система аутентификации.

3. В `.env` оставьте базовые настройки:

   ```dotenv
   AI_BACKEND=sam2-local
   SAM2_MODEL_NAME=facebook/sam2.1-hiera-tiny
   TORCH_NUM_THREADS=2
   API_KEYS=ВАШ_СЛУЧАЙНЫЙ_ДЛИННЫЙ_КЛЮЧ
   ```

4. Соберите и запустите контейнер:

   ```sh
   docker compose build
   docker compose up -d
   docker compose logs -f server
   ```

   Первая сборка скачивает CPU-версию PyTorch и SAM 2. Первая загрузка весов SAM 2 происходит при первом запросе, поэтому ей нужны исходящий доступ в интернет и свободное место в `server/model_cache`. Последующие запросы используют кэш.

5. Проверьте `http://localhost/health`. В режиме по маске ожидается `backend: sam2-local`, `generation_enabled: false`, а после первого успешного запроса `models_loaded: true`. Порт 8001 не опубликован напрямую наружу; снаружи опубликован только Nginx.

6. **Перед публичным релизом настройте HTTPS.** В текущем Nginx-конфиге HTTP на порту 80 предназначен для локального теста или запуска за TLS-терминатором. Не отправляйте production-ключи и фотографии по публичному незашифрованному HTTP.

7. Соберите Flutter release с URL сервера и ключом доступа заказчика:

   ```sh
   cd client
   flutter build apk --release \
     --dart-define=SERVER_URL=https://your-api-domain.example \
     --dart-define=API_KEY=ВАШ_КЛЮЧ
   ```

   Замените `your-api-domain.example` на реально настроенный домен с HTTPS. Не выпускайте приложение с URL `localhost`: на телефоне он указывает на сам телефон, а не на сервер.

## Другие режимы

- `AI_BACKEND=cloudflare` — генеративное редактирование Cloudflare Workers AI. Требуются `CLOUDFLARE_ACCOUNT_ID` и `CLOUDFLARE_API_TOKEN`; действует квота провайдера, и модель может менять детали объекта. Не используйте токен в Flutter-клиенте.
- `AI_BACKEND=local` — более лёгкая эвристическая сегментация без SAM 2. Она оставлена для совместимости/отладки; на сложных сценах с похожими цветами может захватывать соседние предметы. Для сдаваемой версии предпочтителен `sam2-local`.
- `AI_BACKEND=legacy` — старый локальный SAM 2 + Flux/diffusers-конвейер. Ему нужен отдельный GPU-образ и `requirements.ai.txt`; это не рекомендованный бесплатный режим.

Для смены backend отредактируйте `AI_BACKEND` в корневом `.env` и перезапустите контейнер: `docker compose up -d --force-recreate server`.

## Диагностика и проверка

```sh
cd server
python -m pip install -r requirements.txt pytest
python -m pytest -q test_recolor.py test_sam2_segmenter.py
```

Тесты используют синтетические изображения и имитацию предиктора для проверки выбора маски/локальной перекраски — они не расходуют квоту провайдера. Настоящую сегментацию SAM 2 можно проверить только после установки SAM 2 и загрузки модели. Перед релизом также соберите Docker-образ и Flutter-приложение в реальном окружении.

## Ограничения

Ни одна модель сегментации не гарантирует идеальную маску на каждом кадре. Сильно перекрывающиеся предметы, прозрачное стекло и низкоконтрастные границы требуют проверки и иногда дополнительного уточнения. Разница с генеративным Flux в том, что выбранная схема не перерисовывает содержимое предмета: она меняет цвет исходных пикселей, поэтому лучше сохраняет естественные детали.
